# Consultas de Negocio

SCRIPT SQL correspondiente al cuarto entregable. Su objetivo es la extracción de métricas, rankings y comparativas sobre la base de datos `Ventas_Tech_DB`.

## Contenido del script (`m4_consultas_negocio.sql`)
El archivo incluye las 4 consultas requeridas y un bloque final de hallazgos:
1. **Resumen ejecutivo mensual**: Facturación total, cantidad de pedidos y ticket promedio agrupados por mes.
2. **Ranking de productos (Top 5)**: Identificación de los 5 productos con mayores ingresos y sus unidades vendidas.
3. **Clientes recurrentes**: Clientes con más de un pedido realizado, mostrando la cantidad de pedidos y el total gastado.
4. **Análisis por encima/por debajo del promedio**: Clasificación del rendimiento de cada producto respecto a la media.
5. **Bloque de hallazgos**: 3 conclusiones a partir de la realización de las consultas.
